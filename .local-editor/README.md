# 本地内容编辑器

人物移除：通过步骤按钮、进度条或暂停进入某一步后，切换“选择 / 移动”并点击人物，可按 Delete 或点击属性区“移除元素”。从该步骤开始移除人物及后续关联路线，不改变前面的跑动；撤销、重做和保存重开均保留这个范围。点击画布会将键盘焦点切入画布，避免 Delete 落到之前填写的属性或时间输入框。

战术板：打开文章，点击“添加内容 → 战术板”。可使用标准场40×20米或小场30×18米，切换全场、左右半场与横竖方向；球门线始终距端线3.5米，球门后沿距端线2.85米。球门、禁区与标记采用同一几何尺寸，小场是本工具的训练场地选项。

左侧选择球员、守门员、球、标志桶或绘图工具，点击放置、拖动绘图；选择模式可拖动元素，曲线选中后可拖控制点与端点。右侧修改号码、名称、颜色、方向和文字。球员朝向变化时，号码与名称保持正向可读。

点击“下一步”继承当前摆放，再移动球员或球；未设置动作路线时，动作由相邻步骤中同一元素的位置决定；实线直箭头或曲箭头用于无球跑，从球员出发即可关联，播放时只移动人物、不移动球。每步可设置0.2至20秒以及说明，最后一步无动作路线时用于停留。支持步骤复制、前后调整、移除、撤销重做、暂停续播、进度定位与循环。最多100步、180秒，每步150个元素。

点击“插入文章”或“更新战术板”后，还需保存文章。战术板的标题和说明保存在自己的模型中；文章块移动与撤销不改变模型文件，保存重开后点击“编辑战术板”继续修改。公开网站和编辑器预览提供只读播放器。数据与SVG封面按内容哈希保存在 `public/tactics/`，已有版本不覆盖；运行代码与场地图形在 `public/tactics-runtime/`。

“导出图片”保存当前步骤PNG；“导出 MP4”按25fps逐帧渲染、合成并校验H.264/yuv420p/faststart视频，保留当前横竖画幅与比例，最长边1280像素。导出进度可见、可取消，完成后可再次点击“下载 MP4”。临时画面与视频保留在 `.vitepress/cache/content-editor/tactics/`，不自动插入或发布导出视频。完整浏览器验收：`node .local-editor/tests/tactics-browser-check.mjs`，使用9228端口的隔离Edge及缓存内的测试副本。

功能研究参考：[Tactical Board地板球动画](https://tactical-board.com/zh/floorball/animation)、[用户手册](https://tactical-board.com/user-guide/zh.html)。工具代码与矢量图形独立实现；场地几何参考 [IFF 2022规则图示及102节](https://archive.floorball.sport/cloudfront/2022/05/Rules-of-the-Game-2022-Final_updated_18.05.2022.pdf)，这里作为绘图依据，不将30×18米选项表述为官方比赛标准。

三级目录采用“栏目 → 分组 → 页面”。点击左侧“新建分组”或栏目旁的 + 创建分组；页面旁的 ↳ 可选择目标分组，也可直接拖到分组标题，拖回栏目标题则移出分组。分组旁 + 在该组新建页面，普通新建页面弹窗也可选择分组。分组支持铅笔、右键或 F2 改名，↑/↓ 或 Alt+↑/↓ 调整分组顺序；组内页面继续支持拖动和 Alt+↑/↓ 排序。分组保存在 `.local-editor/groups.json`，网站侧边目录同步折叠结构，链接选择器显示所属分组；不移动 Markdown 文件、不修改原有链接。未归组页面仍直接显示在栏目下，排在分组前。

双击仓库根目录的 `启动内容编辑器.cmd`，浏览器打开本机编辑器。保留启动窗口，结束工作后关闭窗口即可。重复启动会打开已有编辑器，不会重复运行服务。

1. 从左侧选择页面，直接在中间编辑标题、正文、列表和表格。
2. 下方“添加内容”用于插入章节、说明框、图片、视频和并排媒体；内容块右上角可调整顺序或移除当前块。
3. 图片和视频可直接从资源管理器拖到中间编辑区的内容块上，在该块之后插入；拖到编辑区空白处则追加。也可从文件选择框或弹窗拖放区域导入，填写说明后插入。导入会保留源文件，并按内容生成唯一文件名，存放于 `public/editor-media/`。支持 MP4、MOV、MKV、WebM、M4V、AVI 视频（单文件不超过1GB），以及 PNG、JPEG、GIF、WebP、AVIF 图片（单文件不超过256MB）。视频会自动压缩并显示上传、排队、压缩和校验进度；相同视频会复用已验证的输出。
4. 右侧实时查看未保存内容的排版，可切换手机宽度和深色模式。点击“网站预览”会在保存后打开完整 VitePress 页面；卡片、特殊组件及站内跳转以完整网站预览为准。
5. 点击“保存页面”或按 Ctrl+S。修改前的原文件备份位于 `.vitepress/cache/content-editor/backups/`；未保存草稿另存于当前浏览器。遇到外部修改冲突时，不覆盖新内容；先复制当前文字，再重新打开页面。

新建页面时选择现有栏目，输入标题，工具自动设置页面样式并加入栏目侧边目录。网站顶栏的分类顺序保持原样。编辑器不执行 Git 提交、推送或部署。

已有 frontmatter、代码、特殊 HTML、组件和无法安全转换的内容显示为“保留内容”，不修改其源码。普通文字块可直接编辑；插入新内容不会重写其他保留块。首页 frontmatter 中的 hero 和分类卡片设置同样保留，不在第一版编辑范围内。

训练页的既有视频尺寸与播放属性在未修改时原样保留，新视频继承网站已有样式。新导入视频自动生成 H.264 / yuv420p / AAC / faststart MP4，最长边不超过1920像素，保留原帧率与宽高比，不上采样小视频。使用 CRF 26 兼顾清晰度与体积；已紧凑且兼容的视频可直接优化封装，不能保证每个源文件都进一步变小。外部原文件不修改，导入副本和中间文件保留在 `.vitepress/cache/content-editor/video/`，只有校验通过的播放文件进入公开媒体目录。视频处理依赖本机已安装的 FFmpeg 与 FFprobe；可通过进程环境变量 `FLOORBALL_FFMPEG`、`FLOORBALL_FFPROBE` 指定程序路径。

## 文件布局

- `server.mjs`：仅监听 127.0.0.1 的本机读写服务与预览启动。
- `document.mjs`：保留源片段的 Markdown 分块、校验和预览。
- `web/`：本地界面、内容序列化和样式。
- `pages.json`：新页面的栏目目录登记，随项目版本维护。
- `tests/`：无损往返、媒体、写入保护与界面流程验证。

开发运行：`npm run editor`。验证：`npm run test:editor`、`npm run build`。

表格：点击当前单元格后，使用工具栏的“表格操作”在上/下插行、左/右插列或删除当前行列。新表格和新增单元格均留空；首行与首列为表头，居中显示，其余正文左上对齐。删除最后一行或一列会移除该表格，可以撤销。

链接：选中文字，点击“链接”，在弹窗中搜索并选择栏目页面，再选择“整篇页面”或某个标题区块。当前页面的新标题无需先保存也可选择。外部链接切换到“外部网址”输入，显示文字可单独修改。

链接使用：点击编辑区或预览中的链接即可跳转。编辑器顶部“返回原文”恢复原页面、未保存的编辑内容和阅读位置。悬停编辑区中的链接，点击“编辑链接”可修改显示文字与目标；也可以 Alt+点击链接打开编辑弹窗，或选中文字后使用工具栏“链接”。“取消链接”保留原文字。

网站阅读时，正文的站内链接在当前标签页跳转后，右下角会显示“返回原文”，可恢复来源页与阅读位置。外部链接继续使用浏览器正常行为。内容中的站内链接使用不含部署前缀的根路径，由 VitePress 添加 `/floorball-training/`；早期带前缀的链接在渲染时兼容处理，不重写原文。

元素标题：表格、图片、视频和并排媒体的顶部可填写独立标题。标题与内容绑定，调整顺序、保存和重开后仍在同一个内容块内；清空标题则恢复无标题元素。标题与内容间距固定为10px，元素组之间保持24px间距。支持单元格内换行的表格保存后继续编辑。

目录排序：直接拖动左侧页面到同栏目目标页面的上方或下方，绿色横线显示插入位置。也可聚焦页面后按 Alt+↑/↓。顺序立即保存到 `.local-editor/order.json`，同步网站侧边目录；不移动文件，不改正文。首页与一级栏目不在此排序范围内。

目录改名：悬停页面或栏目后点击铅笔图标，也可右键名称或聚焦后按 F2。改名后同步编辑器目录、链接选择器和网站导航/侧边目录。只改显示名称，不移动文件、不更改 URL 或文章主标题；原有链接继续有效。显示名称保存在 `.local-editor/names.json`，替换前自动备份。

带球与传球：选择“带球（波浪箭头）”，从球员身上拖到目标位置，会关联该球员；播放时人和球一起沿路线中心移动。选择“传球（虚线箭头）”后拖出路线，播放时球从箭头起点移动到终点；普通箭头或曲线箭头勾选“虚线”也会成为传球路线。起点附近已有球时复用该球，没有球则补一个演示球。每步动作使用该步时长，单步战术也可以播放；点击“下一步”承接人物和球的终点位置，并清除已完成的动作箭头，便于继续画下一段。每位球员或显式关联的球每步只能执行一条路线，分步表达“先带球、再传球”。

无球跑：实线直箭头、实线曲箭头表示不带球移动。从球员身上拖到目标位置，球员按本步时长沿路线跑动，球留在原位；下一步承接球员终点。旧实线箭头会尝试关联起点1.2米内的球员，起点附近没有球员的箭头仍保留标注。实线改为虚线即表示传球。

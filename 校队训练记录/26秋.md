# 训练项目


<div id="editor-block-f4d11d7538ebdaaa"></div>

|  | 项目 |  | 反馈 |
| --- | --- | --- | --- |
| 1 | 两人传球 | **传—停—传，**                  两人约6-8米，接稳再回传，暂时不做一脚出球。以20次为一组，达到平稳传接，再增加距离或力量。 | 正反手接球、身前叩拍面接球 |
| 2 | [板边传接配合](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-fdcc43748dc2f837) | 板边的传接配合。除了接球人背过身往前跑快攻的情况下。**都把球传到拍面上而不是打板**                    ，因为打板不确定性太大了。顺带提一嘴就是大家打板的球要收着一点，因为板子是滑的嘛，达到板子上不是平面反射，他会更往前旋一些。分为两种情形，正手位和反手位的情况。接完球人不要停往前趟然后接一个打门。 | 练习做的不错。强调：<br><ol><li>接球人要往回迎着接接球</li><li>人始终面朝场内而不是背向防守人员</li><li>在实战中传球人尽量传到拍面上而不是打板给边上的人。</li><li>前锋也要积极回撤接球。如果对方前锋压的很深导致边上没有空间回接球，可以考虑去中路接接球。</li></ol> |
| 3 | [传跑练习](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-eb8876c6476f490c) | 传-跑-传-跑-传，见视频 |  |
| 4 | [传接领球练习](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-33f1b5c6e6d268de) | 接球顺势将球引导到需要的方向 |  |
| 5 | [正手弧线带球](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-f4b8d5cf9a766e70) |  |  |
| 6 | [抬头运球练习](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-1888de945246e66e) |  |  |
| 7 | [1v1单挑](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-d0fbd2eedd0bf828) |  |  |

# 26秋训练计划


|  | 项目 |  | 反馈 |
| --- | --- | --- | --- |
| 1 | 两人传球 | **传—停—传，**   两人约6-8米，接稳再回传，暂时不做一脚出球。以20次为一组，达到平稳传接，再增加距离或力量。 |  |
| 2 | [板边传接配合](/%E6%A0%A1%E9%98%9F%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95/26%E7%A7%8B#editor-block-fdcc43748dc2f837) | 板边的传接配合。除了接球人背过身往前跑快攻的情况下。**都把球传到拍面上而不是打板**     ，因为打板不确定性太大了。顺带提一嘴就是大家打板的球要收着一点，因为板子是滑的嘛，达到板子上不是平面反射，他会更往前旋一些。分为两种情形，正手位和反手位的情况。接完球人不要停往前趟然后接一个打门。 |  |

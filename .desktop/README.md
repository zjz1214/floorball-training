# Windows 桌面编辑器

`npm run desktop` 开发运行；`npm run desktop:build` 生成带 Node 和现有 FFmpeg 工具的版本化免安装文件夹，位置为 `desktop-release/`。双击其中 `FloorballEditor.exe`，首次选择本地项目，之后恢复项目选择。

程序依赖选中项目中的 `.local-editor/`、`.vitepress/` 与已安装的 `node_modules/`。项目正文、媒体、备份仍在原项目中，不复制进安装目录。原浏览器编辑器可继续运行，桌面实例使用独立服务端口。

设置与桌面浏览器草稿保存在 Electron userData，日志在其 `logs/` 下。程序只清理自身启动的服务，不终止外部预览；包内包含 Electron 及其开源许可文件。旧构建不自动清理。

Windows 设置目录为 `%APPDATA%\FloorballContentEditor`。文件菜单支持切换项目、保存和打开原项目文件夹；视图菜单提供网页预览与缩放。编辑、视频压缩、表格、目录和战术板继续使用项目中的编辑器。

元素右上角的“复制”或工具栏“复制元素”会复制整个内容块；选择目标元素后点“粘贴元素”，副本插在它后面，未选中时放在页尾。点击元素顶部栏后也可用 Ctrl+C / Ctrl+V。正文或输入框中选中的文字保持普通复制粘贴。支持同项目跨页面粘贴、元素标题及撤销/重做，媒体继续引用原资产，不重复压缩；跨项目请重新导入媒体。

表格单元格支持编号步骤、起始序号与嵌套列表，保存后仍可编辑。添加链接时先选目标页面与区块，可在下方文字预览中划选具体文字，点击“链接到选中文字”，最后插入链接。跳转会突出显示对应文字；文字修改后无法匹配时退回区块定位。链接显示文字可独立修改，“返回原文”保留原阅读位置。

验证命令：`npm run test:desktop`、`npm run test:editor`、`npm run build`。先构建程序，再运行 `node .desktop/smoke.mjs`，会在忽略的缓存目录建立独立项目，验证已打包窗口、视频处理、战术板、保存、草稿恢复、预览与服务退出。测试通过主进程调试接口模拟原生对话框选项，不依赖鼠标点击；普通启动不开放调试接口。测试产物与旧构建均保留。

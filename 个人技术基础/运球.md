# 运球

::: info 与控球训练的区别
本页侧重**带球移动、变向变速、转身护球、假动作与突破**。判断重点是能否带球到达目标位置，并在观察和压力下作出选择。

[控球训练](./控球训练)侧重球感、正反手触球、推拉球和球杆控制。下面的基础动作是运球的前置能力，移动与对抗练习则把这些能力用到比赛情境中。
:::

带球训练要同时解决四件事：**球的路线、球杆的控制、身体的移动，以及动作的用途**。先建立控球能力，再逐步加入观察、假动作和对抗。

## 基本姿势与持杆

- 保持低重心，屈膝后仍能移动和变向。
- 默认双手持杆：双手准备接球，接到球后继续双手控球、带球。
- 单手带球用于特定的伸展或护球情境，不作为新人的默认动作；距离拉开后，要能恢复双手控制。
- 初学时允许看球，熟悉后逐步抬头，观察队友、防守人和可利用的空间。

## 六个基础动作

::: info 教学分类
“拨、推、拉、跨、转、护”是分享讨论中用于组织训练的分类，不是 IFF 官方动作命名。“跨”在这里指球跨过身体中线换边，不是跨越对手球杆。
:::

| 动作 | 训练内容 | 与其他动作的组合 |
| --- | --- | --- |
| 拨 | 正手、反手及正反手连续拨球；切换小幅与宽幅控球 | 连续拨球后向前移动或改变方向 |
| 推 | 向前或横向推球，让球移动到下一个可控位置 | 推球后跟进，再收回或传球 |
| 拉 | 向后、横向拉球；从身体外侧收回球 | 拉球后换边、转身或变速 |
| 跨 | 球从左侧移到右侧，或从右侧移到左侧 | 拉球换边后跨步启动 |
| 转 | 正手、反手控球配合转身，改变朝向 | 护球后转身摆脱 |
| 护 | 调整球的位置，让身体位于对手与球之间 | 护球后转身、传球或移动出压力区域 |

### 用五个维度拆解动作

| 维度 | 可以改变的内容 |
| --- | --- |
| 触球方式 | 正手、反手、连续拨球；小幅高频与大幅低频 |
| 推拉方向 | 向前推、向后拉、横向推拉、正反手转换 |
| 球与身体的位置 | 左右换边、身前到身侧、近处到远处、外侧收回 |
| 脚步与速度 | 原地、前进、后退、横移、斜向、急停、启动、转身、变速 |
| 欺骗信号 | 杆头、球、肩部、重心、目光，以及传球或射门假动作 |

同一种拨球动作，可以配不同脚步和观察任务。设计训练时，先确定要练哪个维度，再安排动作组合。

## 从控球到对抗的进阶顺序

| 阶段 | 重点 | 可用练习 |
| --- | --- | --- |
| 1. 控住球 | 熟悉正反手、推拉与近身控球 | 原地拨球，前后拉推 |
| 2. 带球移动 | 球与脚步配合 | 前进、后退、横移、转弯 |
| 3. 改变球的位置 | 调整球与身体的相对位置 | 宽拉、收球、跨身体换边、身前转身侧 |
| 4. 改变运动状态 | 保持控球同时停、转、启动 | 急停启动、变向变速、正反手转身 |
| 5. 观察 | 边控球边读取信息 | 看教练手势，观察队友与空间 |
| 6. 假动作 | 让身体或球给出信号，再改变方向 | 肩部假动作、假射、假传、停顿后加速 |
| 7. 对抗 | 在压力下护球并作选择 | 被动防守、1v1、狭小空间控球 |

这是一条增加难度的教学顺序。护球、观察和身体姿势可以在前面阶段穿插练习，不必等到最后才开始。

### 每次只增加一个变量

例如保持“正反手连续拨球”这个任务，依次加入：

**原地 → 走动 → 提速 → 横向移动 → 抬头 → 随机方向信号 → 被动防守 → 1v1。**

每步先确认队员仍能控制球，再增加难度。不要同时要求新人提速、抬头和应对主动抢球。

## 变向、转身与假动作

### 左侧假动作后向右突破

1. 用熟悉的拍面控住球，先向左侧带球。
2. 肩部或重心给出向左移动的信号。
3. 观察防守人的反应；有右侧空间时，把球拉回右侧。
4. 跨步换方向，再加速离开防守人的范围。

左右方向可镜像练习。重点是控球、观察和启动衔接，而不是预设防守人一定会被假动作骗走。

### 正反手运球转身

先原地练转身时球的位置，再加入行进和被动防守。转身前收好球，用身体保护球；转身后观察是否适合继续带球、传球或射门。

### 带球停顿

用减速或短暂停顿改变节奏，再根据空间选择启动、换边或出球。停顿期间仍要能护住球。

## 一次基础带球训练模块

下面按分享讨论整理为约 **23–24 分钟**的模块，可根据队员水平调整。每人一球，移动练习注意间距；对抗练习单独划分区域。

| 环节 | 时间 | 安排 |
| --- | --- | --- |
| 原地球感 | 3–4 分钟 | 正反手拨球，身前与身侧控球，宽窄幅切换 |
| 移动控球 | 5 分钟 | 从直线到 S 型绕桩，再逐步提速 |
| 抬头观察 | 5 分钟 | 看教练举手、数字或方向信号，并作出响应 |
| 变向与假动作 | 5 分钟 | 在标志桶前变向，分别尝试正手、反手及身体假动作 |
| 压力下控球 | 5 分钟 | 从被动防守过渡到 1v1 护球 |

训练结束时检查：是否能控住球、响应观察任务，以及在压力下选择带球或出球。详细的组织与练习可继续阅读 [带球与控制](../训练计划/带球与控制)。

## 查找训练视频的关键词

以 `floorball` 为运动关键词，再组合控杆、移动或对抗目标。

| 目标 | 搜索关键词 |
| --- | --- |
| 基础控杆与球感 | `floorball stickhandling drills`、`floorball ball control drills` |
| 新人基础 | `floorball beginner drills`、`floorball basic skills` |
| 原地左右拨球 | `floorball tic tac dribbling` |
| 移动与绕桩 | `floorball dribbling drills`、`floorball cone dribbling drills` |
| 变向与变速 | `floorball change of direction drills`、`floorball speed dribbling` |
| 护球与小空间控制 | `floorball ball protection drills`、`floorball tight space stickhandling` |
| 抬头控球 | `floorball head up dribbling` |
| 假动作与突破 | `floorball fakes drills`、`floorball dekes`、`floorball 1v1 drills` |
| 单手控制 | `floorball one hand stickhandling` |
| 全队热身与分站练习 | `floorball warm up with ball`、`floorball team dribbling drills`、`floorball station drills` |

看视频时先确认训练目的、适用水平和前置动作，再决定如何放进训练课。

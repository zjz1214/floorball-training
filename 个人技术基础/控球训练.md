# 控球训练

::: info 本页练什么
控球训练侧重**球感和球杆控制**：正反手触球、推拉球、控制触球幅度，以及让球保持在可控范围。原地与绕标练习都围绕这些能力展开。

[运球](./运球)侧重**带着球完成移动任务**：前进、变向变速、转身护球，以及突破和出球。两者会用到相同的触球动作，区别在于训练目标。
:::

# 个人技术基础


::: info 说明
- 虽然按照基础和进阶做了区分，但是实际上即使是基础部分也没那么基础，学习这一章的前提条件是已经掌握了基本的控球和传接球技术。
- 我觉得基本功的掌握优先级是控球运球\>传球\>防守\>射门的，但是也不意味着要一个个学，而是每项技术都同步提升，不断提升自己掌握的技术。
:::
